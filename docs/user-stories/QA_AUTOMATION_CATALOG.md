# Developer / QA Automation Catalog

## Purpose

This catalog maps the Developer / QA coverage-suite IDs from `FEATURE_CATALOG.md` and `SYSTEM_OPERATIONS_USER_STORIES.md` to existing feature-owned requirements, test-case packages, and automation evidence.

QA-001 through QA-004 are coverage-suite IDs. They do not own product behavior and must not duplicate feature-owned test cases.
