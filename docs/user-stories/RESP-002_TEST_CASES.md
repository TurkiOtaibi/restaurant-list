# RESP-002 Test Cases - Safe-area aware layout

## Source Requirements

- Feature: `RESP-002 - Safe-area aware layout`
- Sources: `RESPONSIVE_ACCESSIBILITY_USER_STORIES.md`, `docs/feature-map/FEATURE_TRACEABILITY.md`
- User stories processed: `RESP-002-US-001` through `RESP-002-US-024`
- Feature ownership: responsive certification matrix, no horizontal overflow, overflow masking prohibition, top and bottom safe areas, dynamic viewport behavior, virtual keyboard reachability, dialog and sheet viewport fit, landscape/tablet/desktop layout, long content containment, loading/error/menu layout, and browser matrix coverage.
