## Documented Contract

- Refresh endpoint: `POST /api/v1/auth/refresh`.
- Refresh request relies on an HttpOnly refresh cookie, not a JavaScript-readable refresh token.
- Successful refresh returns `200 OK`.
- Successful `RefreshResponse` body contains `accessToken` only.
- Successful refresh rotates the refresh token: current refresh token record is revoked and a new refresh token cookie/record is issued.
- Missing, expired, malformed, deleted-user, or reused refresh token returns `401`.
- Reused old rotated refresh token revokes active refresh tokens for the user/session family.
- Refreshed access token is stored in memory only and never in localStorage, sessionStorage, URL, logs, or error payloads.
- Protected screens show loading/pending while refresh resolves and do not flash private data.
- Web Locks, BroadcastChannel, and documented fallbacks coordinate multi-tab refresh state.
- Access token lifetime defaults to 15 minutes unless configured otherwise.
- Refresh token lifetime defaults to 30 days unless configured otherwise.
- Refresh responses and refresh errors must not expose raw refresh token, token hash, JWT claims, secrets, stack traces, debug payloads, internal identifiers, or private user data.

## Response And Storage Assertions

| Assertion ID | Required Assertion |
|---|---|
| ASSERT-SUCCESS-REFRESH-001 | Response status is `200 OK`; JSON body has exactly one top-level field: `accessToken`; response body does not include `refreshToken`, `user`, `session`, `tokenHash`, `claims`, `debug`, `stack`, `internalId`, or private user data. |
| ASSERT-ERROR-REFRESH-001 | Response status is `401`; no `accessToken` is issued; response body and headers do not include raw refresh token, token hash, JWT claims, cookie value, secrets, stack trace, debug payload, internal identifiers, or private user data. |
| ASSERT-STORAGE-REFRESH-001 | localStorage, sessionStorage, document-accessible cookies, current URL, console logs, network error payloads, and rendered DOM contain no raw refresh token. |
| ASSERT-STORAGE-ACCESS-001 | localStorage, sessionStorage, URL, console logs, network error payloads, and rendered DOM contain no refreshed access token. Access token is observable only through successful authenticated request state. |
| ASSERT-NO-PRIVATE-FLASH-001 | DOM text, accessibility tree text, network error payloads, and console logs contain none of `PRIVATE-LIST-CANARY-001`, `PRIVATE-PLACE-CANARY-001`, `PRIVATE-RATING-CANARY-001`, or `PRIVATE-PROFILE-CANARY-001` before refresh resolves or after refresh fails. |
