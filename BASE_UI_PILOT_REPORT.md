# Base UI Pilot Report

## Executive Summary

This PR implements the first Base UI pilot as a narrow proof of compatibility.

The pilot installs `@base-ui/react` and uses exactly one Base UI primitive: `Tooltip`. The tooltip is used once on the `/profile` page as supplementary helper text for the ratings count stat.

No backend, API, auth/session, database, migration, routing, bottom navigation, Dialog, Menu, ActionMenu, ResponsiveDialog, shadcn component, or product behavior was changed.

## Why Tooltip Was Chosen

Tooltip was selected because it is a low-risk primitive:

- It is non-mutating.
- It does not replace a critical app interaction.
- It does not affect routing, forms, dialogs, menus, or API state.
- It can prove Base UI portal/layer behavior without migrating complex primitives.

The tooltip content is supplementary only. Per Base UI guidance, tooltips are not used for critical information and are not relied on for touch or screen reader access.

## Accessibility Notes

- The trigger is a real button generated by `Tooltip.Trigger`.
- The trigger has an Arabic accessible name matching the tooltip text.
- The visible `؟` glyph is `aria-hidden` because the accessible name is supplied on the trigger.
- The trigger uses a 44px touch target.
- Focus-visible styling remains available.
- The tooltip is supplementary, not required to complete any task.
- Base UI tooltips are designed for hover/focus and are not relied on as the only access path for critical content.

## RTL Notes

- The tooltip popup uses `dir="rtl"`.
- The trigger is positioned with logical properties: `inset-block-start` and `inset-inline-end`.
- Tooltip text is Arabic.
- Existing `dir="rtl"` document behavior is unchanged.
- The pilot did not add directional arrows or LTR-only layout assumptions.

## Portal / Layering Notes

- `Tooltip.Portal` is used through Base UI.
- `body` now has `isolation: isolate` and `position: relative` to keep portal/layer behavior predictable.
- Tooltip popup z-index is scoped to the tooltip classes.
- No global dialog/menu layering was changed.

## Known Risks

- Base UI Tooltip is intentionally supplementary and not touch-first. Do not use it for critical mobile information.
- The Base UI package increases the frontend shared JS payload; future pilots should continue to monitor bundle impact.
- More complex primitives such as Dialog, Menu, Select, Combobox, Popover, and Form remain unproven and should not be migrated without a dedicated PR and screenshots.

## Recommendation For Next Base UI Candidate

Next candidate:

- A non-critical presentational/assistive primitive only after this PR is reviewed.
